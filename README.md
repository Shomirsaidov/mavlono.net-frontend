# mavlono.net — client (Nuxt 4, server-side rendered)

Poem, poet, biography and catalog pages are rendered on the server so search engines
receive complete HTML plus per-page `<title>`, description, Open Graph / Twitter tags,
canonical URL and JSON-LD (see `app/composables/useSeo.js`).

```sh
npm install
npm run dev        # http://localhost:3000 (set VITE_API_URL in .env to your API)
npm run build && npm start   # production Node server (.output/)
```

Env: `VITE_API_URL` (API origin, build-time), optional `NUXT_API_URL` (runtime API origin
for the sitemap) and `NUXT_PUBLIC_SITE_URL` (default https://www.mavlono.net).

- `/sitemap.xml` and `/robots.txt` are generated by `server/routes/`.
- Client-only (not SSR, noindex): `/admin/**`, `/profile`, `/users/**`, `/write`, `/settings`, `/auth`.
- Deploy on a Node-capable host (Vercel/Render/…); static hosting of `dist/` no longer works.
